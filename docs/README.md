# 102 업무자동화

반복되는 업무를 줄이기 위해서 만들었습니다.
앱인벤터에서 영감을 받았습니다. 

**마우스·키보드 입력을 녹화하듯 블록으로 만들어 쉽게 이용할 수 있습니다.**
엑셀의 값을 열 단위로 가져올 수 있습니다. 

추가기능은 블럭을 만들어서 사용할 수 있도록 이 방법을 선택했습니다.

AI와 상관없는 파이썬 자동화 코드입니다.


## 사용 방법
이미지를 누르면 유튜브에서 설명 영상이 재생됩니다.

[![사용 방법 영상](https://img.youtube.com/vi/E9QhYblxbB4/hqdefault.jpg)](https://youtu.be/E9QhYblxbB4)


## 실행
```bash
main.bat
```
실행전 `setup.bat` 으로 필요한 패키지를 설치하세요 (오류는 `error.log` 에 남습니다)

## 폴더 구성
```
main.py        앱 실행 (블록 편집 화면)
make_launcher.py  저장한 프로젝트(JSON)를 실행 파일(exe, bat)로 만들기 / 바로 실행
main.bat        콘솔 창 없이 main.py 실행
setup.bat      필요한 파이썬 패키지 설치
core/          핵심 코드 (engine, recorder, datetime_blocks)와 화면(web/)
docs/          문서 (README, THIRD_PARTY_NOTICES)
```
`LICENSE`, `requirements.txt`, `.gitignore` 는 맨 위에 있습니다. 설치 명령은 맨 위 폴더에서 실행하세요.

## 블록
| 블록 | 설명 |
|---|---|
| 만약 … 이면 / 아니면 | 조건에 따라 실행할 블록을 나눔. 조건: 영업일 확인, 값 비교(=, ≠, >, ≥, <, ≤), 그리고/또는, 아니다, 비어 있음 |
| 웹사이트 열기 | 주소(텍스트 블록)를 기본 브라우저로 열고 페이지가 뜰 때까지 기다림 (http/https 만) |
| 프로그램 열기 | exe, bat, 바로가기 파일을 실행하고 창이 뜰 때까지 기다림 |
| 엑셀 각 줄마다 실행 | 파일/시트/열/행을 정하면 한 줄씩 내려가며 안쪽 블록을 실행 (.xlsx, .xls) |
| 엑셀 값, 엑셀 줄 번호 | 엑셀 블록 안에서 현재 줄의 값과 번호 |
| 반복 N번, 계속 반복 | 일반 반복 (ESC 로 중지) |
| 타이핑 | 값을 복사해 붙여넣기 (한글도 안전) |
| 특수키 | Enter, Tab, Delete, Backspace, 방향키 |
| 대기 | 지정한 초만큼 기다림 |
| 녹화 실행 | 마우스·키보드 동작을 녹화(ESC 로 종료)하고 재생 |
| 날짜, 시간 | 오늘/지금을 원하는 형식(2026-01-02, 260102, 14:30 …)으로 돌려줌. 숫자로 더하고 뺄 수 있음 (일·주·개월·년·영업일 / 시간·분·초) |
| 휴일 설정, 휴일 날짜, 휴일 기간 | 연결하지 않고 아무 곳에나 두는 설정 블록. 토/일 휴무를 고르고, 안쪽에 휴일 날짜(하루)와 휴일 기간(연휴) 블록을 이어 붙이면 날짜 블록의 '영업일' 계산에 쓰임 |
| 텍스트, 텍스트 합치기, 숫자 | 값 블록 |

## 사용 팁
- 실행하면 3초 뒤 시작하고 앱 창이 최소화됩니다. 실행 중 `ESC` 로 중지할 수 있습니다.
- 구글 시트에서 칸을 내려가며 입력할 때는 `Enter` 대신 `아래 화살표` 를 쓰세요. (Enter 는 편집 모드로 들어갑니다)
- 녹화는 마우스 좌표를 그대로 저장하므로 창 위치나 해상도가 바뀌면 어긋납니다.
- 관리자 권한으로 실행된 창에는 녹화·재생이 되지 않습니다. 필요하면 앱도 관리자 권한으로 실행하세요.
- 마우스와 키보드를 대신 조작하는 도구입니다. 실행 전에 대상 창과 입력 위치를 꼭 확인하세요.
