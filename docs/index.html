102 업무자동화

반복되는 업무를 블록으로 조립하세요.
마우스·키보드 입력을 녹화하고, 엑셀 값을 열 단위로 가져옵니다.

ZIP 다운로드

Windows · Python 3 필요 · 무료 · GitHub에서 보기

주요 기능

🧩 블록 코딩

앱인벤터처럼 블록을 끌어다 놓기만 하면 자동화 완성. AI와 무관한 순수 파이썬 코드입니다.

🎬 녹화 실행

마우스·키보드 동작을 녹화(ESC로 종료)하고 그대로 재생합니다.

📊 엑셀 연동

.xlsx/.xls 파일의 열을 한 줄씩 내려가며 안쪽 블록을 반복 실행합니다.

📅 날짜·영업일

오늘/지금을 원하는 형식으로, 휴일을 설정해 영업일 계산까지.

⌨️ 안전한 타이핑

복사해 붙여넣는 방식이라 한글도 깨지지 않습니다.

🛑 ESC로 즉시 중지

실행 중 언제든 ESC 한 번으로 멈춥니다.

사용 방법 영상

▶

3단계로 시작

  1. 위의 ZIP 다운로드 후 압축을 풉니다.
  2. setup.bat 실행 — 필요한 패키지가 설치됩니다.
  3. main.pyw 실행 — 블록을 조립하고 실행!

사용 팁

  • 실행하면 3초 뒤 시작하고 앱 창이 최소화됩니다. ESC로 중지.
  • 녹화는 좌표 기반이라 창 위치·해상도가 바뀌면 어긋납니다.
  • 관리자 권한 창에는 앱도 관리자 권한으로 실행하세요.
  • 마우스와 키보드를 대신 조작하는 도구입니다. 실행 전 대상 창을 꼭 확인하세요.
